# 🛒 Amazon Homepage Clone
A fully responsive Amazon homepage clone built using HTML5 and CSS3. This project recreates the look and feel of Amazon's landing page while focusing on clean code, responsive layouts, and modern frontend development practices.

## 🚀 Features
- Responsive Navigation Bar
- Search Bar UI
- Hero Banner Section
- Product Cards & Shopping Sections
- Multiple Category Boxes
- Amazon-style Footer
- Hover Effects & Smooth Transitions
- Clean and Organized File Structure

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
  
## 📁 Project Structure

Amazon-Clone/
│── index.html
│── webpage.css
│── images/
│── README.md

## 🎯 Project Objective
The goal of this project was to strengthen my frontend development skills by recreating a real-world e-commerce homepage. Throughout the development process, I practiced responsive design, semantic HTML, CSS layouts, Flexbox, Grid, positioning, and UI design while paying close attention to detail.
